# 백준 25311번
## 제목: UCPC에서 가장 쉬운 문제 번호는?
## 입력
첫 줄에 UCPC 개최 연도 y가 주어집니다. (2018 <= y <= 2022)

### 요약
2018 < y < 2022 (y == 2019, 2020, 2021)

## 출력
 y년도 UCPC 예선의 출제진이 의도한 가장 쉬운 문제의 번호를 영어 대문자 알파벳 한 글자로 출력하세요.

### 요약
A 출력

## 입출력 예시
### 예시 1
#### 입력
```
0
```

#### 출력
```
YONSEI
```

## 제한사항
- 시간제한: 0.5초
- 메모리 제한: 1024MB
- 난이도: 브론즈 V
- 사용 언어: PYTHON
