# 백준 1759번
## 제목: 암호 만들기
## 입력
첫째 줄에 두 정수 L, C가 주어진다. (3 ≤ L ≤ C ≤ 15) 다음 줄에는 C개의 문자들이 공백으로 구분되어 주어진다. 주어지는 문자들은 알파벳 소문자이며, 중복되는 것은 없다.

### 요약
L: 암호의 길이 \
C: 사용된 문자

## 출력
각 줄에 하나씩, 사전식으로 가능성 있는 암호를 모두 출력한다.

### 요약
만들 수 있는 모든 조합을 오름차순으로 정렬

## 입출력 예시
### 예시 1
#### 입력
```
4 6
a t c i s w
```

#### 출력
```
acis
acit
aciw
acst
acsw
actw
aist
aisw
aitw
astw
cist
cisw
citw
istw
```

## 제한사항
- 시간제한: 2초
- 메모리 제한: 128MB
- 난이도: 골드 V
- 사용 언어: PYTHON
