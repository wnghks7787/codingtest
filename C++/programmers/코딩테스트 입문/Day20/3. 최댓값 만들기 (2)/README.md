# 프로그래머스 입문 Day20-3
## 제목: 최댓값 만들기 (2)
## 문제 설명
정수 배열 `numbers`가 매개변수로 주어집니다. `numbers`의 원소 중 두 개를 곱해 만들 수 있는 최댓값을 return하도록 solution 함수를 완성해주세요.

## 입출력 예시
### 예시 1
#### 입력
```
[1, 2, -3, 4, -5]
```

#### 출력
```
15
```

### 예시 2
#### 입력
```
[0, -31, 24, 10, 1, 9]
```

#### 출력
```
240
```

### 예시 3
#### 입력
```
[10, 20, 30, 5, 5, 20, 5]
```

#### 출력
```
600
```


## 제한사항
- -10,000 ≤ `numbers`의 원소 ≤ 10,000
- 2 ≤ `numbers` 의 길이 ≤ 100
- 사용 언어: C++
