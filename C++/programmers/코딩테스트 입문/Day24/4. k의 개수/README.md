# 프로그래머스 입문 Day24-4
## 제목: k의 개수
## 문제 설명
1부터 13까지의 수에서, 1은 1, 10, 11, 12, 13 이렇게 총 6번 등장합니다. 정수 `i`, `j`, `k`가 매개변수로 주어질 때, `i`부터 `j`까지 `k`가 몇 번 등장하는지 return 하도록 solution 함수를 완성해주세요.

## 입출력 예시
### 예시 1
#### 입력
```
i: 1
j: 13
k: 1
```

#### 출력
```
6
```

### 예시 2
#### 입력
```
i: 10
j: 50
k: 5
```

#### 출력
```
5
```

### 예시 3
#### 입력
```
i: 3
j: 10
k: 2
```

#### 출력
```
0
```


## 제한사항
- 1 ≤ `i` < `j` ≤ 100,000
- 0 ≤ `k` ≤ 9
- 사용 언어: C++
