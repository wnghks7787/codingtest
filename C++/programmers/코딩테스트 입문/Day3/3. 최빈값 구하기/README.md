# 프로그래머스 입문 Day3-3
## 제목: 최빈값 구하기
## 입력
정수 배열이 주어진다.


## 출력
가장 많이 나온 값을 구한다. 만약 가장 많이 나온 값이 두 개 이상이면 -1을 반환한다.

## 입출력 예시
### 예시 1
#### 입력
```
[1, 2, 3, 3, 3, 4]
```

#### 출력
```
3
```

### 예시 2
#### 입력
```
[1, 1, 2, 2]
```

#### 출력
```
-1
```

### 예시 3
#### 입력
```
[1]
```

#### 출력
```
1
```

## 제한사항
- 0 < array 길이 < 100
- -1000 <= array 원소 < 1000
- 사용 언어: C++
