# 프로그래머스 입문 Day2-3
## 제목: 분수의 덧셈
## 입력
네 개의 정수가 입력된다.
각각 첫 번째 분수의 분자/분모, 두 번째 분수의 분자/분모 이다.


## 출력
두 분수를 더했을 때 나타나는 값을 기약 분수로 나타냈을 때의 분자/분모 값을 vector로 내보낸다.

## 입출력 예시
### 예시 1
#### 입력
```
numer1 = 1
denom1 = 2
numer2 = 3
denom2 = 4
```

#### 출력
```
[5, 4]
```

### 예시 2
#### 입력
```
numer1 = 9
denom1 = 2
numer2 = 1
denom2 = 3
```

#### 출력
```
[29, 6]
```

- 0 < numer1, denom1, numer2, denom2 <= 1000
- 사용 언어: C++
