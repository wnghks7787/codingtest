# 프로그래머스 입문 Day2-1
## 제목: 두 수의 나눗셈
## 입력
두 개의 정수가 주어진다.


## 출력
num1에서 num2를 나눈 뒤 1000을 곱한 값을 출력한다.

## 입출력 예시
### 예시 1
#### 입력
```
num1 = 3
num2 = 2
```

#### 출력
```
1500
```

### 예시 2
#### 입력
```
num1 = 7
num2 = 3
```

#### 출력
```
2333
```

### 예시 3
#### 입력
```
num1 = 1
num2 = 16
```

#### 출력
```
62
```

## 제한사항
- 0 < num1, num2 <= 100
- 사용 언어: C++
