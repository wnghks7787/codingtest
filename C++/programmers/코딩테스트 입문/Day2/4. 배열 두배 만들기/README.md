# 프로그래머스 입문 Day2-4
## 제목: 배열 두배 만들기
## 입력
정수 배열이 하나 주어진다.


## 출력
입력된 정수 배열을 두 배로 만들어서 내보낸다.

## 입출력 예시
### 예시 1
#### 입력
```
[1, 2, 3, 4, 5]
```

#### 출력
```
[2, 4, 6, 8, 10]
```

### 예시 2
#### 입력
```
[1, 2, 100, -99, 1, 2, 3]	
```

#### 출력
```
[2, 4, 200, -198, 2, 4, 6]
```

- -10,000 ≤ numbers의 원소 ≤ 10,000
- 1 ≤ numbers의 길이 ≤ 1,000
- 사용 언어: C++
