# 프로그래머스 입문 Day2-2
## 제목: 숫자 비교하기
## 입력
두 개의 정수가 주어진다.


## 출력
두 수가 같으면 1, 다르면 -1을 출력한다.

## 입출력 예시
### 예시 1
#### 입력
```
num1 = 2
num2 = 3
```

#### 출력
```
-1
```

### 예시 2
#### 입력
```
num1 = 11
num2 = 11
```

#### 출력
```
1
```

### 예시 3
#### 입력
```
num1 = 7
num2 = 99
```

#### 출력
```
-1
```

- 0 <= num1, num2 <= 10000
- 사용 언어: C++
