# 프로그래머스 입문 Day6-4
## 제목: 문자 반복 출력하기
## 문제 설명
문자열 `my_string`과 정수 `n`이 매개변수로 주어질 때, `my_string`에 들어있는 각 문자를 `n`만큼 반복한 문자열을 return 하도록 solution 함수를 완성해보세요.

## 입출력 예시
### 예시 1
#### 입력
```
my_string = "hello"
n = 3
```

#### 출력
```
"hhheeellllllooo"
```

## 제한사항
- 2 ≤ `my_string` 길이 ≤ 5
- 2 ≤ `n` ≤ 10
- "my_string"은 영어 대소문자로 이루어져 있습니다.
- 사용 언어: C++
