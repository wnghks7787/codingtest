# 프로그래머스 입문 Day8-4
## 제목: 순서쌍의 개수
## 문제 설명
순서쌍이란 두 개의 숫자를 순서를 정하여 짝지어 나타낸 쌍으로 (a, b)로 표기합니다. 자연수 `n`이 매개변수로 주어질 때 두 숫자의 곱이 `n`인 자연수 순서쌍의 개수를 return하도록 solution 함수를 완성해주세요.

## 입출력 예시
### 예시 1
#### 입력
```
20
```

#### 출력
```
6
```

### 예시 2
#### 입력
```
100
```

#### 출력
```
9
```

## 제한사항
- 1 ≤ n ≤ 1,000,000
- 사용 언어: C++
