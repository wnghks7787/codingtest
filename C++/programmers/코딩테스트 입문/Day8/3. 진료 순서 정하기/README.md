# 프로그래머스 입문 Day8-3
## 제목: 진료 순서 정하기
## 문제 설명
외과의사 머쓱이는 응급실에 온 환자의 응급도를 기준으로 진료 순서를 정하려고 합니다. 정수 배열 `emergency`가 매개변수로 주어질 때 응급도가 높은 순서대로 진료 순서를 정한 배열을 return하도록 solution 함수를 완성해주세요.

## 입출력 예시
### 예시 1
#### 입력
```
[3, 76, 24]
```

#### 출력
```
[3, 1, 2]
```

### 예시 2
#### 입력
```
[1, 2, 3, 4, 5, 6, 7]
```

#### 출력
```
[7, 6, 5, 4, 3, 2, 1]
```

### 예시 3
#### 입력
```
[30, 10, 23, 6, 100]
```

#### 출력
```
[2, 4, 3, 5, 1]
```


- 중복된 원소는 없습니다.
- 1 ≤ `emergency`의 길이 ≤ 10
- 1 ≤ `emergency`의 원소 ≤ 100
- 사용 언어: C++
