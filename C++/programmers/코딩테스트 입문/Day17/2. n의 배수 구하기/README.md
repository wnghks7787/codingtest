# 프로그래머스 입문 Day17-2
## 제목: n의 배수 구하기
## 문제 설명
정수 `n`과 정수 배열 `numlist`가 매개변수로 주어질 때, `numlist`에서 `n`의 배수가 아닌 수들을 제거한 배열을 return하도록 solution 함수를 완성해주세요.

## 입출력 예시
### 예시 1
#### 입력
```
n = 3
numlist = [4, 5, 6, 7, 8, 9, 10, 11, 12]
```

#### 출력
```
[6, 9, 12]
```

### 예시 2
#### 입력
```
n = 5
numlist = [1, 9, 3, 10, 13, 5]
```

#### 출력
```
[10, 5]
```

### 예시 3
#### 입력
```
n = 12
numlist = [2, 100, 120, 600, 12, 12]
```

#### 출력
```
[120, 600, 12, 12]
```

## 제한사항
- 1 ≤ `n` ≤ 10,000
- 1 ≤ `numlist`의 크기 ≤ 100
- 1 ≤ `numlist`의 원소 ≤ 100,000
- 사용 언어: C++
