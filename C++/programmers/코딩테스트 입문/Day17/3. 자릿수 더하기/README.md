# 프로그래머스 입문 Day17-3
## 제목: 자릿수 더하기
## 문제 설명
정수 `n`이 매개변수로 주어질 때 `n`의 각 자리 숫자의 합을 return하도록 solution 함수를 완성해주세요

## 입출력 예시
### 예시 1
#### 입력
```
1234
```

#### 출력
```
10
```

### 예시 2
#### 입력
```
930211
```

#### 출력
```
16
```

## 제한사항
- 0 ≤ `n` ≤ 1,000,000
- 사용 언어: C++
