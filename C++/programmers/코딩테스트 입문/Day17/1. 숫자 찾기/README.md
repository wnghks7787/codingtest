# 프로그래머스 입문 Day17-1
## 제목: 숫자 찾기
## 문제 설명
정수 `num`과 `k`가 매개변수로 주어질 때, `num`을 이루는 숫자 중에 `k`가 있으면 `num`의 그 숫자가 있는 자리 수를 return하고 없으면 -1을 return 하도록 solution 함수를 완성해보세요.

## 입출력 예시
### 예시 1
#### 입력
```
num = 29183
k = 1
```

#### 출력
```
3
```

### 예시 2
#### 입력
```
num = 232443
k = 4
```

#### 출력
```
4
```

### 예시 3
#### 입력
```
num = 123456
k = 7
```

#### 출력
```
-1
```

## 제한사항
- 0 < `num` < 1,000,000
- 0 ≤ `k` < 10
- `num`에 `k`가 여러 개 있으면 가장 처음 나타나는 자리를 return 합니다.
- 사용 언어: C++
