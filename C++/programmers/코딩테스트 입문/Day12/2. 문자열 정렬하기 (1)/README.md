
# 프로그래머스 입문 Day12-2
## 제목: 문자열 정렬하기 (1)
## 문제 설명
문자열 'my_string'이 매개변수로 주어질 때, `my_string` 안에 있는 숫자만 골라 오름차순 정렬한 리스트를 return 하도록 solution 함수를 작성해보세요.

## 입출력 예시
### 예시 1
#### 입력
```
"hi12392"
```

#### 출력
```
[1, 2, 2, 3, 9]
```

### 예시 2
#### 입력
```
"p2o4i8gj2"
```

#### 출력
```
[2, 2, 4, 8]
```

### 예시 3
#### 입력
```
"abcde0"
```

#### 출력
```
[0]
```

## 제한사항
- 1 ≤ `my_string`의 길이 ≤ 100
- `my_string`에는 숫자가 한 개 이상 포함되어 있습니다.
- `my_string`은 영어 소문자 또는 0부터 9까지의 숫자로 이루어져 있습니다. 
- 사용 언어: C++
