
# 프로그래머스 입문 Day12-3
## 제목: 숨어있는 숫자의 덧셈 (1)
## 문제 설명
문자열 `my_string`이 매개변수로 주어집니다. `my_string`안의 모든 자연수들의 합을 return하도록 solution 함수를 완성해주세요.

## 입출력 예시
### 예시 1
#### 입력
```
"aAb1B2cC34oOp"
```

#### 출력
```
10
```

### 예시 2
#### 입력
```
"1a2b3c4d123"
```

#### 출력
```
16
```

## 제한사항
- 1 ≤ `my_string`의 길이 ≤ 1,000
- `my_string`은 소문자, 대문자 그리고 한자리 자연수로만 구성되어있습니다.
- 사용 언어: C++
