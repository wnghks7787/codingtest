# 프로그래머스 입문 Day10-4
## 제목: 배열 회전시키기
## 문제 설명
정수가 담긴 배열 `numbers`와 문자열 `direction`가 매개변수로 주어집니다. 배열 `numbers`의 원소를 `direction`방향으로 한 칸씩 회전시킨 배열을 return하도록 solution 함수를 완성해주세요.

## 입출력 예시
### 예시 1
#### 입력
```
numbers = [1, 2, 3]
direction = "right"
```

#### 출력
```
[3, 1, 2]
```

### 예시 2
#### 입력
```
numbers = [4, 455, 6, 4, -1, 45, 6]
direction = "left"
```

#### 출력
```
[455, 6, 4, -1, 45, 6, 4]
```


## 제한사항
- 3 ≤ `numbers`의 길이 ≤ 20
- `direction`은 "left" 와 "right" 둘 중 하나입니다.
- 사용 언어: C++
