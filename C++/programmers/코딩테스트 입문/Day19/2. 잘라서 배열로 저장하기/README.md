# 프로그래머스 입문 Day19-2
## 제목: 잘라서 배열로 저장하기
## 문제 설명
문자열 `my_str`과 n이 매개변수로 주어질 때, `my_str`을 길이 `n`씩 잘라서 저장한 배열을 return하도록 solution 함수를 완성해주세요.

## 입출력 예시
### 예시 1
#### 입력
```
my_str = "abc1Addfggg4556b"
n = 6
```

#### 출력
```
["abc1Ad", "dfggg4", "556b"]
```

### 예시 2
#### 입력
```
my_str = "abcdef123"
n = 3
```

#### 출력
```
["abc", "def", "123"]
```


## 제한사항
- 1 ≤ `my_str`의 길이 ≤ 100
- 1 ≤ `n` ≤ `my_str`의 길이
- `my_str`은 알파벳 소문자, 대문자, 숫자로 이루어져 있습니다.
- 사용 언어: C++
