# 프로그래머스 입문 Day25-3
## 제목: 연속된 수의 합
## 문제 설명
연속된 세 개의 정수를 더해 12가 되는 경우는 3, 4, 5입니다. 두 정수 `num`과 `total`이 주어집니다. 연속된 수 `num`개를 더한 값이 `total`이 될 때, 정수 배열을 오름차순으로 담아 return하도록 solution함수를 완성해보세요.

## 입출력 예시
### 예시 1
#### 입력
```
num: 3
total: 12
```

#### 출력
```
[3, 4, 5]
```

### 예시 2
#### 입력
```
num: 5
total: 15
```

#### 출력
```
[1, 2, 3, 4, 5]
```

### 예시 3
#### 입력
```
num: 4
total: 14
```

#### 출력
```
[2, 3, 4, 5]
```

### 예시 4
#### 입력
```
num: 5
total: 5
```

#### 출력
```
[-1, 0, 1, 2, 3]
```


## 제한사항
- 1 ≤ `num` ≤ 100
- 0 ≤ `total` ≤ 1000
- `num`개의 연속된 수를 더하여 `total`이 될 수 없는 테스트 케이스는 없습니다.
- 사용 언어: C++
