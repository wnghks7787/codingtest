# 프로그래머스 입문 Day9-3
## 제목: 가위 바위 보
## 문제 설명
가위는 2 바위는 0 보는 5로 표현합니다. 가위 바위 보를 내는 순서대로 나타낸 문자열 `rsp`가 매개변수로 주어질 때, `rsp`에 저장된 가위 바위 보를 모두 이기는 경우를 순서대로 나타낸 문자열을 return하도록 solution 함수를 완성해보세요.

## 입출력 예시
### 예시 1
#### 입력
```
"2"
```

#### 출력
```
"0"
```

### 예시 2
#### 입력
```
"205"
```

#### 출력
```
"052"
```


- 0 < `rsp`의 길이 ≤ 100
- `rsp`와 길이가 같은 문자열을 return 합니다.
- `rsp`는 숫자 0, 2, 5로 이루어져 있습니다.
- 사용 언어: C++
