## 제목: 약수 바꾸기
## 문제 설명

## 입출력 예시
### 예시 1
#### 입력
```
24
```

#### 출력
```
[1, 2, 3, 4, 6, 8, 12, 24]
```

### 예시 2
#### 입력
```
29
```

#### 출력
```
[1, 29]
```

## 제한사항
- 1 ≤ `n` ≤ 10,000
- 사용 언어: C++
