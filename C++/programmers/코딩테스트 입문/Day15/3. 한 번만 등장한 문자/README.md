# 프로그래머스 입문 Day15-2
## 제목: 인덱스 바꾸기
## 문제 설명
문자열 `s`가 매개변수로 주어집니다. `s`에서 한 번만 등장하는 문자를 사전 순으로 정렬한 문자열을 return 하도록 solution 함수를 완성해보세요. 한 번만 등장하는 문자가 없을 경우 빈 문자열을 return 합니다.

## 입출력 예시
### 예시 1
#### 입력
```
"abcabcadc"
```

#### 출력
```
"d"
```

### 예시 2
#### 입력
```
"abdc"
```

#### 출력
```
"abcd"
```

### 예시 3
#### 입력
```
"hello"
```

#### 출력
"eho"
```

## 제한사항
- 0 < `s`의 길이 < 1,000
- `s`는 소문자로만 이루어져 있습니다.
- 사용 언어: C++
