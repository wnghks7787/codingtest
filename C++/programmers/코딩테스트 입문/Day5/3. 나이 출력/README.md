# 프로그래머스 입문 Day5-3
## 제목: 나이 출력
## 문제 설명
머쓱이는 선생님이 몇 년도에 태어났는지 궁금해졌습니다. \
2022년 기준 선생님의 나이 `age`가 주어질 때, 선생님의 출생 연도를 return 하는 solution 함수를 완성해주세요

## 입출력 예시
### 예시 1
#### 입력
```
40
```

#### 출력
```
1983
```

### 예시 2
#### 입력
```
23
```

#### 출력
```
2000
```

## 제한사항
- 0 < age ≤ 120
- 나이는 태어난 연도에 1살이며 매년 1월 1일마다 1살씩 증가합니다.
- 사용 언어: C++
