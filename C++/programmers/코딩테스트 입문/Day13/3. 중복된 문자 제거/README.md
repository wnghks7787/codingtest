# 프로그래머스 입문 Day13-3
## 제목: 중복된 문자 제거
## 문제 설명
문자열 `my_string`이 매개변수로 주어집니다. `my_string`에서 중복된 문자를 제거하고 하나의 문자만 남긴 문자열을 return하도록 solution 함수를 완성해주세요.
## 입출력 예시
### 예시 1
#### 입력
```
"people"
```

#### 출력
```
"peol"
```

### 예시 2
#### 입력
```
"We are the world"
```

#### 출력
```
"We arthwold"
```


## 제한사항
- 1 ≤ `my_string` ≤ 110
- `my_string`은 대문자, 소문자, 공백으로 구성되어 있습니다.
- 대문자와 소문자를 구분합니다.
- 공백(" ")도 하나의 문자로 구분합니다.
- 중복된 문자 중 가장 앞에 있는 문자를 남깁니다.
- 사용 언어: C++
