# 프로그래머스 입문 Day14-1
## 제목: 가까운 수
## 문제 설명
정수 배열 `array`와 정수 n이 매개변수로 주어질 때, `array`에 들어있는 정수 중 n과 가장 가까운 수를 return 하도록 solution 함수를 완성해주세요.

## 입출력 예시
### 예시 1
#### 입력
```
array: [3, 10, 28]
n: 20
```

#### 출력
```
28
```

### 예시 2
#### 입력
```
array: [10, 11, 12]
n: 13
```

#### 출력
```
12
```

## 제한사항
- 1 ≤ `array`의 길이 ≤ 100
- 1 ≤ `array`의 원소 ≤ 100
- 1 ≤ `n` ≤ 100
- 가장 가까운 수가 여러 개일 경우 더 작은 수를 return 합니다.
- 사용 언어: C++
