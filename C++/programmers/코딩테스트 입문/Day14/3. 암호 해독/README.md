# 프로그래머스 입문 Day14-3
## 제목: 암호 해독
## 문제 설명
군 전략가 머쓱이는 전쟁 중 적군이 다음과 같은 암호 체계를 사용한다는 것을 알아냈습니다.
- 암호화된 문자열 `cipher`를 주고받습니다.
- 그 문자열에서 `code`의 배수 번째 글자만 진짜 암호입니다.
문자열 `cipher`와 정수 `code`가 매개변수로 주어질 때 해독된 암호 문자열을 return하도록 solution 함수를 완성해주세요.

## 입출력 예시
### 예시 1
#### 입력
```
cipher = "dfjardstddetckdaccccdegk"
code = 4
```

#### 출력
```
"attack"
```

### 예시 2
#### 입력
```
cipher = "pfqallllabwaoclk"
code = 2
```

#### 출력
```
"fallback"
```

## 제한사항
- 1 ≤ `cipher`의 길이 ≤ 1,000
- 1 ≤ `code` ≤ `cipher`의 길이
- `cipher`는 소문자와 공백으로만 구성되어 있습니다.
- 공백도 하나의 문자로 취급합니다.
- 사용 언어: C++
