# 백준 31450번
## 제목: Everyone is a winner
## 입력
The input consists of one line. This line contains two space-separated integers $M$ and $K$: $M$ is the number of medals and $K$ is the number of kids.

### 요약
M: 메달의 수
K: 아이들의 수

## 출력
The output should contain a single line, consisting of a word: the word Yes if it is possible to give out all $M$ medals to the $K$ kids so that each kid gets the same number of medals, or the word No otherwise.

### 요약
모든 메달을 나누어주었을 때, 아이들이 모두 같은 양의 메달을 받을 수 있으면 `Yes`, 그렇지 않으면 `No`를 출력한다.

## 입출력 예시
### 예시 1
#### 입력
```
6 3
```

#### 출력
```
Yes
```

### 예시 2
#### 입력
```
5 3
```

#### 출력
```
No
```
