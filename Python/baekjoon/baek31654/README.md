# 백준 31654번
## 제목: ADDING TROUBLE
## 입력
The input consists of a single line with 3 integers $A, B, C$ where $-10^9 \le A, B, C \le 10^9$.

### 요약
입력 A, B: 두 수
입력 C: 예측하는 두 수의 합

## 출력
Output either correct! if $A + B = C$, or wrong! if $A + B \ne C$.

### 요약
A+B가 C이면 `correct!`, 아니면 `wrong!` 출력

## 입출력 예시
### 예시 1
#### 입력
```
2 3 5
```

#### 출력
```
correct!
```

### 예시 2
#### 입력
```
1 1 3
```

#### 출력
```
wrong!
```

### 예시 3
#### 입력
```
-1 1 0
```

#### 출력
```
correct!
```
