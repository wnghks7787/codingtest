# 백준 15680
## 제목: 연세대학교
## 입력
첫째 줄에 N이 주어진다. (N = 0 또는 1)

### 요약
0 or 1 입력

## 출력
- N = 0일 경우: 연세대학교의 영문명을 출력한다.
- N = 1일 경우: 연세대학교의 슬로건을 출력한다.

대소문자 구별에 주의하도록 하자.

### 요약
0일 때: YONSEI
1일 때: Leading the Way to the Future

## 입출력 예시
### 예시 1
#### 입력
```
0
```

#### 출력
```
YONSEI
```

## 제한사항
- 시간제한: 1초
- 메모리 제한: 128MB
- 난이도: 브론즈 V
- 사용 언어: PYTHON
