# 백준 4779번
## 제목: 칸토어 집합
## 입력
입력을 여러 줄로 이루어져 있다. 각 줄에 N이 주어진다. 파일의 끝에서 입력을 멈춘다. N은 0보다 크거나 같고, 12보다 작거나 같은 정수이다.

### 요약
입력 N이 1개 이상 들어올 수 있다. (0<= n >= 12)

## 출력
입력으로 주어진 N에 대해서, 해당하는 칸토어 집합의 근사를 출력한다.

### 요약
입력 N에 대하여 '-'로 이루어진 칸토어 집합의 근사를 (3등분 하여 가운데를 제거하는 것을 반복하는 것)을 출력한다.

## 입출력 예시
### 예시 1
#### 입력
```
0
1
3
2
```

#### 출력
```
-
- -
- -   - -         - -   - -
- -   - -
```
