# 백준 1182번
## 제목: 부분수열의 합
## 입력
첫째 줄에 정수의 개수를 나타내는 N과 정수 S가 주어진다. (1 ≤ N ≤ 20, |S| ≤ 1,000,000) 둘째 줄에 N개의 정수가 빈 칸을 사이에 두고 주어진다. 주어지는 정수의 절댓값은 100,000을 넘지 않는다.

### 요약
두 정수 N과 S를 입력한 뒤, N 크기의 수열이 입력된다.

## 출력
첫째 줄에 합이 S가 되는 부분수열의 개수를 출력한다.

### 요약
S를 만족하는 부분수열의 갯수를 하나 출력한다.

## 입출력 예시
### 예시 1
#### 입력
```
5 0
-7 -3 -2 5 8
```

#### 출력
```
1
```
