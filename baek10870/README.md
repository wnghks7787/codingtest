# 백준 10870번
## 제목: 피보나치 수 5
## 입력
첫째 줄에 n이 주어진다. n은 20보다 작거나 같은 자연수 또는 0이다.

### 요약
20 이하의 자연수 혹은 0이 입력으로 하나 주어진다. (0 <= n >= 20)

## 출력
첫째 줄에 n번째 피보나치 수를 출력한다.

### 요약
n번째 피보나치 숫자를 출력한다. 총 결과는 1개

## 입출력 예시
### 예시 1
#### 입력
```
10
```

#### 출력
```
55
```

- 시간제한: 1초
- 메모리 제한: 256MB
- 난이도: 브론즈 II
