# 백준 11650번
## 제목: 좌표 정렬하기
## 입력
첫째 줄에 점의 개수 N (1 ≤ N ≤ 100,000)이 주어진다. 둘째 줄부터 N개의 줄에는 i번점의 위치 $x_i$와 $y_i$가 주어진다. (-100,000 ≤ $x_i$, $y_i$ ≤ 100,000) 좌표는 항상 정수이고, 위치가 같은 두 점은 없다.

### 요약
입력 받을 좌표의 갯수를 먼저 입력한 뒤, 그 횟수만큼 좌표(x, y)가 입력된다

## 출력
첫째 줄부터 N개의 줄에 점을 정렬한 결과를 출력한다.

### 요약
정렬된 좌표를 순서대로 출력한다.

## 입출력 예시
### 예시 1
#### 입력
```
5
3 4
1 1
1 -1
2 2
3 3
```

#### 출력
```
1 -1
1 1
2 2
3 3
3 4
```
